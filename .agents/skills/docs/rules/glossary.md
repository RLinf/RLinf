# Glossary

One term per concept, in both languages. When a page needs a term that is missing here, add it in the same change. Code identifiers are never translated and do not belong in this table.

| English term | Chinese term | Note |
|---|---|---|
| policy (RL) | policy | not 策略; a generic strategy, such as a placement strategy, is 策略 |
| rollout | rollout | not 展开 |
| worker, actor, critic | worker, actor, critic | |
| env (in prose) | 环境 | write `env_type` and other identifiers as they are |
| heterogeneous envs | 异构环境 | several env configurations in one run; "multiple envs" means parallel copies of one env |
| env configuration | 环境配置 | not "named config", "entry", or "mode" |
| simulator | 模拟器 | |
| real robot, real-world | 真机 | |
| New Real-World Tasks | 新增真机任务 | page and caption name |
| robot part (`RobotPart`) | 零部件 | |
| action part (`action_parts`) | 动作项 | |
| GPU memory | 显存 | |
| checkpoint | checkpoint | |
| placement | placement | placement 策略 |
| config key | 配置项 | |
| training, inference, fine-tuning | 训练、推理、微调 | |
| dataset, weights | 数据集、权重 | |
