# RLinf Documentation Style Guide

The documentation rules live in the `docs` skill, split by page type and by language so that a writer reads only what the page in hand needs:

- [Rules for every page](../.agents/skills/docs/rules/base.md), with the table of page types.
- Page types: [recipe](../.agents/skills/docs/rules/recipe.md), [guide](../.agents/skills/docs/rules/guide.md), [concept](../.agents/skills/docs/rules/concept.md), [extending](../.agents/skills/docs/rules/extending.md), [reference](../.agents/skills/docs/rules/reference.md), [index and navigation](../.agents/skills/docs/rules/index.md), [publication](../.agents/skills/docs/rules/publication.md), and [README highlights](../.agents/skills/docs/rules/readme.md).
- Languages: [English](../.agents/skills/docs/rules/english.md), [中文](../.agents/skills/docs/rules/chinese.md), and the [glossary](../.agents/skills/docs/rules/glossary.md).
- [Mistakes agents make in docs and prose](../.agents/skills/docs/rules/mistakes.md), and page [templates](../.agents/skills/docs/templates/).

To check a change, run `python3 .agents/skills/docs/check.py`; [the skill](../.agents/skills/docs/SKILL.md) describes the whole workflow.
