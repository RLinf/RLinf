克隆仓库：

.. code:: bash

   git clone https://github.com/RLinf/RLinf.git
   cd RLinf

使用下面的 ``requirements/install.sh`` 命令安装依赖，或从 `Docker Hub <https://hub.docker.com/r/rlinf/rlinf>`__ 拉取预构建镜像。通用安装选项见 :doc:`/rst_source/start/installation`。
