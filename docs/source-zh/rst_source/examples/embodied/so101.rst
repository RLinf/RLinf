SO-101 配置与 SFT
=================

.. figure:: https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/SO101_Follower.webp
   :align: center
   :width: 70%

   SO-101 follower 及其夹爪。图片来源：Hugging Face LeRobot。

在连接机械臂的 Linux 主机上完成 SO-101 全流程：硬件校准与自检、主从臂遥操作与 LeRobot 示教采集、OpenPI SFT 训练，以及本地 fixed-checkpoint 评测。

概览
----

采集、SFT 与本地评测全部在同一套 Linux 主机环境下运行，并共用 ``SO101ReachEnv-v1`` 的 6 维关节空间表示。

观测与动作
~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 24 76

   * - 字段
     - 说明
   * - 观测
     - 已配置相机的 RGB 图像，加标准 6 维状态（5 个弧度制绝对关节角与 ``[0, 1]`` 夹爪开度）。
   * - 动作
     - 标准 6 维目标（5 个弧度制绝对关节角与夹爪开度 ``0=闭合，1=张开``），在 ``pi05_so101_joint`` 中填充至 32 维。
   * - 奖励
     - 采集与评测均由操作者通过键盘标注（``a`` 开始/放弃，``b`` 切换分段/失败，``c`` 保存成功）。
   * - 指令
     - 采集与评测 YAML 中的 ``task_description``\ （须与 SFT 一致）。

硬件与安全准备
--------------

.. list-table::
   :header-rows: 1
   :widths: 28 72

   * - 组件
     - 要求
   * - Follower（从臂）
     - SO-101 机械臂、夹爪、舵机控制板与套件指定电源。
   * - Leader（主臂，可选）
     - 接在独立 USB 串口的 SO-101 主臂，用于遥操作与示教采集。
   * - 控制主机
     - 通过 USB 连接 Feetech 舵机控制板与相机的 Linux 主机；运行 OpenPI SFT 与评测需配备 GPU。

未组装的机械臂请先按 `LeRobot SO-101 指南 <https://huggingface.co/docs/lerobot/so101>`__ 完成装配，并在串联接线前逐个配置新电机 ID。

.. warning::

   硬件模式下，启动脚本会沿限速平滑轨迹将从臂折叠至 ``[0, -99, 95, 65, 0]`` 度休止姿态（默认 30 度/秒；可用 ``--reset-speed 10`` 降速，或用 ``--no-reset`` 跳过启动复位）。启动前请清空折叠路径。RLinf worker 不会交互式标定机械臂，请先在运行账号下完成标定，且不可用主臂标定文件替代从臂标定。

.. dropdown:: 新电机或更换电机的 ID 配置

   全新或更换后的 Feetech 电机需按上游接线顺序逐个写入 ID 与波特率（已配置好的机械臂可跳过）：

   .. code-block:: bash

      lerobot-setup-motors \
        --robot.type=so101_follower \
        --robot.port=/dev/ttyACM0

   每次仅接入提示指定的单个电机；全部 6 个电机配置完成后，再完成组装并接回串联线缆。

安装与运行
----------

.. include:: _setup_common.rst

.. tab-set::

   .. tab-item:: 1. 安装与校准

      **1. 安装 RLinf**

      安装 SO-101 环境（包含 OpenPI、LeRobot 与 Feetech 电机依赖）：

      .. code-block:: bash

         git clone https://github.com/RLinf/RLinf.git && cd RLinf
         bash requirements/install.sh embodied --model openpi --env so101 && source .venv/bin/activate

      **2. 查找串口并检查权限**

      接通从臂舵机控制板 USB 与电源，查找串口路径（示例假设为 ``/dev/ttyACM0``）：

      .. code-block:: bash

         lerobot-find-port
         ls -l /dev/ttyACM0
         id -nG

      若串口属 ``dialout`` 组且当前用户未加入该组，运行 ``sudo usermod -aG dialout "$USER"``，退出并重新登录，重新激活 ``.venv`` 后再次确认串口路径。

      **3. 标定从臂**

      在 RLinf 打开串行总线前完成终端标定（将标定文件保存在运行账号下，并保持 ``--id rlinf_follower`` 一致）：

      .. code-block:: bash

         lerobot-calibrate \
           --robot.type=so101_follower \
           --robot.port=/dev/ttyACM0 \
           --robot.id=rlinf_follower

      **4. 运行硬件自检**

      清空折叠路径，先关闭相机发现（``CAMERA_SERIALS=''``）单独检查关节与夹爪：

      .. code-block:: bash

         CAMERA_SERIALS='' python -m toolkits.realworld_check.test_so101_env \
           --port /dev/ttyACM0 --id rlinf_follower --step 2

      逐条输入以下指令并等待运动完成（``up``/``down`` 让肩关节增减 2 度，输入 ``help`` 查看其他关节；环境配置中 ``reset_joint_speed`` 单位为弧度每秒，``reset_duration`` 默认 3 秒）：

      .. code-block:: text

         where
         up
         down
         open
         close
         quit

   .. tab-item:: 2. 遥操作与数据采集

      **1. 标定主臂并验证遥操作**

      用独立串口与 ID 标定 SO-101 主臂，再启动带相机的遥操作检查（``--enable-camera-player`` 用于实时预览画面）：

      .. code-block:: bash

         lerobot-calibrate \
           --teleop.type=so101_leader \
           --teleop.port=/dev/ttyACM1 \
           --teleop.id=rlinf_leader

         python -m toolkits.realworld_check.test_so101_env \
           --port /dev/ttyACM0 --id rlinf_follower \
           --leader /dev/ttyACM1 --leader-id rlinf_leader \
           --fps 30 --enable-camera-player

      从臂折叠就位后，将主臂摆至相同姿态并输入 ``teleop``，按一次 Ctrl-C 退回提示符，再输入 ``quit`` 断开。相机独立采帧（默认复用不超过 ``camera_max_age`` 0.5 秒的图像）；夹爪遇阻停滞时会自动保持实测开度以泄压，待主臂远离受阻位置后再继续移动（显式开合指令仍会等待运动到位或泄压完成）。

      **2. 采集示教数据**

      在 ``examples/embodiment/config/realworld_so101_collect_data_joint.yaml`` 中填好主从臂串口、标定 ID、相机设备、核对后的 reset 姿态与 ``task_description``，在仓库根目录启动采集：

      .. code-block:: bash

         bash examples/embodiment/collect_data.sh realworld_so101_collect_data_joint

      按键说明：``a`` 开始或放弃录制、``b`` 切换分段、``c`` 保存成功 episode、``q`` 安全退出；主机接有多个键盘时设置 ``RLINF_KEYBOARD_DEVICE`` 指向稳定的 ``/dev/input/by-id/...`` 路径。数据写入运行目录的 ``collected_data``；需要合并多次采集或导出 MP4 预览画面时，可在计算统计量与训练前使用 ``toolkits/lerobot/merge_lerobot_datasets.py`` 与 ``toolkits/lerobot/visualize_lerobot_dataset.py``。

      **3. 计算 OpenPI 归一化统计量**

      将 ``HF_LEROBOT_HOME`` 指向最终数据集根目录的父目录，生成填充后的 32 维 ``state`` 与 ``actions`` 统计量：

      .. code-block:: bash

         export HF_LEROBOT_HOME=/absolute/path/to/datasets
         python -m toolkits.lerobot.calculate_norm_stats \
           --config-name pi05_so101_joint \
           --repo-id so101_dataset

      将 ``Writing stats to:`` 后输出的 ``norm_stats.json`` 路径填入 ``openpi_data.norm_stats_path``\ （SFT 对应 ``actor.model.openpi_data.norm_stats_path``，评测对应 ``rollout.model.openpi_data.norm_stats_path``；训练和评测都不会在 ``full_weights.pt`` 同级目录自动查找该文件）。

   .. tab-item:: 3. SFT 与本地评测

      **1. 运行 OpenPI SFT 训练**

      编辑 ``examples/sft/config/realworld_sft_openpi_so101.yaml``，或直接通过 Hydra CLI 参数传入数据集根目录（包含 ``meta/info.json``）、基座 checkpoint 与 ``norm_stats.json`` 路径：

      .. code-block:: bash

         bash examples/sft/run_vla_sft.sh realworld_sft_openpi_so101 \
           data.train_data_paths=./so101_dataset \
           actor.model.model_path=./pi05_base_pytorch \
           actor.model.openpi_data.norm_stats_path=./assets/pi05_so101_joint/so101_dataset/norm_stats.json

      **2. 本地 Fixed-Checkpoint 评测**

      在 ``examples/embodiment/config/realworld_so101_eval_openpi.yaml`` 中更新从臂串口、标定 ID、相机设备、核对后的 reset 姿态及与 SFT 一致的 ``task_description``。在 ``examples/embodiment/config/model/so101_pi05.yaml`` 中填写与 ``pi05_so101_joint`` 兼容的 checkpoint 与对应的 ``norm_stats.json``，或直接通过 Hydra CLI 参数传入：

      .. code-block:: bash

         bash evaluations/run_eval.sh realworld_so101_eval_openpi \
           rollout.model.model_path=./logs/checkpoints/global_step_10000 \
           rollout.model.openpi_data.norm_stats_path=./assets/pi05_so101_joint/so101_dataset/norm_stats.json

      按 ``a`` 开始评测 episode，按 ``c`` 记录成功，按 ``b`` 记录失败。

结果与常见问题
--------------

在主机上运行 ``tensorboard --logdir ./logs --port 6006`` 观察 SFT 损失，并在训练或评测前确认 ``norm_stats.json`` 包含 32 维 ``state`` 与 ``actions`` 条目，指标说明见 :doc:`训练指标 <../../reference/metrics>`。

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 现象
     - 解决方法
   * - 打开 ``/dev/ttyACM0`` 报权限不足
     - 运行 ``sudo usermod -aG dialout "$USER"``，退出重新登录、激活 ``.venv`` 并用 ``lerobot-find-port`` 重新核对串口。
   * - Worker 连接从臂失败
     - 在运行 RLinf 的同一 Linux 账号下运行 ``lerobot-calibrate`` 并传入一致的 ``--id``，不可复用主臂标定文件。
   * - 夹爪碰到物体后停止推进
     - 停滞保护已将夹爪保持在实测开度以泄压，先将主臂夹爪略微退开再重试。
   * - 需要合并多次采集数据训练 SFT
     - SFT 只读取单个数据集根目录且不自动合并，请先合并为一个 LeRobot dataset 再基于合并后的数据计算 ``norm_stats.json``。
   * - 键盘快捷键无响应
     - 确认运行账号有权读取 ``/dev/input``，并将 ``RLINF_KEYBOARD_DEVICE`` 设为 ``/dev/input/by-id/...`` 路径。

如需编程控制机械臂或接入相机，参见 :doc:`机器人接口 <../../concepts/robotics>`；如需在 ``SO101ReachEnv-v1`` 之外构建自定义任务，参见 :doc:`新增真机任务 <../../extending/new_task>`。
