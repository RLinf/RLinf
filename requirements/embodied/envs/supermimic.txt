# torch==2.14.0+cu126 is the CUDA 12.6 wheel
# torch-2.14.0+cu126-cp311-cp311-manylinux_2_28_x86_64.whl
# on https://download.pytorch.org/whl/cu126
# The unsuffixed PyPI torch==2.14.0 depends on CUDA 13 (cuda-toolkit 13.0.3)
# and is not usable with driver 566.26. The +cu126 local version stops pip
# from selecting that wheel. mjlab commit 8bb2bc9's cu126 lock resolved the
# newer torch==2.14.1+cu126; 2.14.0+cu126 still satisfies torch>=2.14.0.
# These pins are not a Warp / MuJoCo Warp / PyTorch CUDA runtime check.
#
# PyPI and pypi.nvidia.com publish warp-lang==1.18.0 built with CUDA 13.4.
# That wheel needs driver >= 13.0 and does not see this machine's driver
# 566.26 (CUDA 12.7). The line below is the CUDA 12 build of the same Warp
# version, warp-lang==1.18.0+cu12, from the v1.18.0 GitHub release. It is
# not on those indexes. Do not add https://pypi.nvidia.com here: a later
# install would replace this wheel with the CUDA 13 build.
